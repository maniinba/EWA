# Sample EWA reports

Synthetic EarlyWatch Alert reports for trying the upload flow. They contain no
real customer data — generated by `app/services/sample_generator.py`.

Upload one via the **Reports** page, or with curl:

```bash
TOKEN=$(curl -s -X POST http://localhost:8000/api/auth/token \
  -d 'username=admin@example.com&password=admin' | python -c 'import sys,json;print(json.load(sys.stdin)["access_token"])')

curl -X POST http://localhost:8000/api/reports/upload \
  -H "Authorization: Bearer $TOKEN" \
  -F "file=@backend/sample_data/EWA_PRD_2026-08-04.pdf"
```

Regenerate:

```bash
cd backend && python -c "from datetime import date; from app.services.sample_generator import build_report_pdf; open('sample_data/EWA_PRD_2026-08-04.pdf','wb').write(build_report_pdf('PRD', date(2026,8,4)))"
```
